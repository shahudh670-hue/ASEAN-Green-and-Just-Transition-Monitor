# ASEAN Green and Just Transition Monitor

An open, fully client-side dashboard that tracks the energy transition across the eleven ASEAN members alongside the things that decide whether it is fair and financeable: human development, multidimensional poverty, fiscal space, external debt, domestic capital markets and international finance flows.

**Live site:** https://shahudh670-hue.github.io/ASEAN-Green-and-Just-Transition-Monitor/

The monitor asks one question: where can scarce public and concessional finance unlock the most private and domestic investment in a transition that also improves people's lives?

## Interactive features

- Linked choropleth map and ranking: hover in one, see it in the other; click to highlight a country everywhere on the page (up to four, colour stays with the country).
- Year slider with play-through animation, regional aggregate options (GDP- or population-weighted, median, or total) and IMF projections on demand.
- Trend chart with zoom, rebasing to 100 and a full-member tooltip; a country-by-year heat grid that moves the whole page to the clicked year.
- Relationship explorer: any two indicators, bubble size by population or GDP, log scales, animated years and trails.
- Country profiles with the energy mix (total energy supply over time and electricity generation, from UN energy statistics), the coal fleet, and latest values, five-year change judged against each indicator's direction, rank and sparkline.
- Automated policy insights generated by fixed, tested rules, each with the numbers used and a one-click jump to the chart behind it.
- Poverty and energy tab: national and sub-national MPI map with circles sized by the number of poor, a profile for any country or region, survey energy deprivation set against the SDG 7 series, a typology of regions with similar deprivation profiles, OPHI's harmonised changes over time, and generated options for national action and ASEAN cooperation.
- Table view, CSV and PNG download on every chart; shareable links that preserve the full view; light and dark themes.

## How the data pipeline works

`scripts/etl/run.mjs` pulls every series directly from its official interface:

- World Bank Indicators API v2 (WDI and International Debt Statistics)
- IMF DataMapper API (World Economic Outlook and Fiscal Monitor)
- UN SDG Global Database API (SDG 7.a.1)
- UNDP HDRO composite indices time series (CSV)
- ILOSTAT API (employment by economic activity)
- OECD climate-related development finance and private finance mobilised (Excel files)
- OECD and IISD Fossil Fuel Subsidy Tracker (Excel file)
- IMF Climate Change Indicators Dashboard (CSV)
- Global Energy Monitor, Global Coal Plant Tracker summary tables
- UN Statistics Division energy statistics (SDMX API)

The 2026 global MPI tables, the FY2027 income classification, the sub-regional framework territories and the IRENA jobs table are small published tables kept in `config/static/`, with their sources. The MPI tables are extracted from OPHI's workbooks with `scripts/mpi/extract_mpi.py`, and the sub-national boundaries are built from geoBoundaries with `scripts/mpi/build_mpi_geo.py`; rerun both when OPHI publishes a new release.

The pipeline derives the debt-composition and ODA-share series, checks results against reference values recorded when the indicator set was designed (`config/reference-checks.json`), and writes `public/data/data.json` plus a long-format CSV. If a source is unreachable, the previous values are kept and the failure is shown on the *Sources and methods* page. Nothing is imputed.

The GitHub Actions workflow in `.github/workflows/deploy.yml` runs the pipeline, the tests and the build on every push and on the 2nd of each month, then publishes to GitHub Pages.

## Run it locally

```bash
npm ci
npm run data     # fetch the data (needs internet access)
npm test         # unit tests for the insight rules and the poverty tables
npm run dev      # local server
```

## Visual design

A hybrid editorial and UNDP style: ice-blue page, flat white panels with sharp corners and thin borders, a 4px UNDP blue band with a blank red geometric tag at the top left, Inter for titles, menus and numbers, PT Serif for narrative subtitles, and charts with transparent backgrounds, horizontal gridlines only and square bar ends. No logos are used.
